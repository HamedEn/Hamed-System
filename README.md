# Hamed's System v3

## التشغيل
ارفع المجلد كاملاً على أي استضافة HTTPS (Firebase Hosting / Netlify / GitHub Pages) وافتح index.html.
أول دخول: تعيّن رمز قفل (4-8 أرقام). بعدها تدخل فيه من أي جهاز بنفس الرمز.

## قاعدة البيانات (Firebase Realtime Database)
البيانات تحت العقدة `hamed_system_v3`. قواعد الأمان الحالية في مشروعك غالباً مفتوحة؛ راجعها من Firebase Console > Realtime Database > Rules.
الرمز مخزّن كـ hash (PBKDF2) وليس نصاً صريحاً، لكن القواعد المفتوحة تعني أن أي شخص يعرف رابط القاعدة يقدر يقرأ بياناتك.

## التنبيهات
تعمل والتطبيق مفتوح (حتى بتبويب خلفي). للتنبيه والتطبيق مغلق تماماً يلزم Firebase Cloud Messaging + Cloud Function (خطة Blaze).

## v4 — ما الجديد
مساعد ذكي محلي مجاني (أيقونة قابلة للسحب) • سجل حضور/غياب + موضوع الدرس + وين وصلت + نقاط الضعف • وجاهي/عن بُعد لكل موعد • تبديل مادة شخصية لليوم فقط • استراحات (نوم/وجبات/نشاط) • واجبات بتذكير دقيق • اختبارات تعدّل الجدول تلقائياً أيام التحضير • تقارير يومي/أسبوعي/شهري/شهرين • بصمة • فاتح/داكن • استيراد JSON.
البيانات متوافقة مع v3 (نفس عقدة Firebase)، فلا حاجة لنقل شيء. للبصمة يلزم HTTPS.

## v4.1 — النسخة النهائية
تسجيل ما بعد الحصة (حضور + موضوع + وين وصلت + واجبات) • نظام نقاط ومستويات وأوسمة وجوائز • طباعة/PDF للجدول اليومي والأسبوعي (من تبويب الجدول، اختر «حفظ كـ PDF») • مزامنة كل الأجهزة عبر Firebase (نفس الرابط + نفس الرمز، والمظهر يتزامن) • Service Worker للتثبيت والعمل دون اتصال وتنبيهات أندرويد.
## النشر
ارفع كل محتويات المجلد (بما فيه sw.js) على استضافة HTTPS. راجع قواعد Firebase Realtime Database لتقييد الوصول.
